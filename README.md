# Masking Remover - 수업용 가림판 및 순차 공개 도구

> **수업 교재(PDF, 이미지)의 문제 정답, 핵심 키워드, 해설 부분을 드래그로 가리고 순서에 따라 차례대로 지워주는 웹 기반 수업 도구입니다.**

---

## 🌟 주요 기능

1. **문서 및 이미지 완벽 지원**
   - **PDF 파일 업로드**: `PDF.js` 엔진을 통해 다중 페이지 문서를 선명하게 렌더링하고 페이지별 마스킹을 각각 보존합니다.
   - **이미지 업로드**: PNG, JPG, WEBP, GIF 등 지원.
   - **드래그 앤 드롭**: 브라우저 창 위에 파일을 끌어다 놓으면 즉시 열립니다.
   - **샘플 교재 기본 탑재**: 실행하자마자 바로 사용법을 체험할 수 있는 인터랙티브 예시 학습지가 제공됩니다.

2. **직관적인 가림판(마스킹) 생성, 텍스트 입력 및 드래그 앤 드롭 이동**
   - 마우스나 스마트패드/전자칠판 터치 드래그로 원하는 영역에 사각형 가림판을 쉽게 생성합니다.
   - 가림판 생성 순서에 따라 **①, ②, ③...** 순번 배지가 자동으로 부여됩니다.
   - **이미 생성된 마커 드래그 앤 드롭 이동**: 이미 배치된 가림판 박스를 마우스로 끌어다 놓아 자유롭게 위치를 이동할 수 있습니다 (상대 좌표계 % 자동 갱신).
   - **가림판 텍스트 입력**: 가림판을 **더블 클릭**하거나 사이드바 목록에서 힌트/단어/정답 텍스트를 직접 입력할 수 있습니다.
   - 창 크기 변경이나 확대/축소(Zoom)에도 가림판 위치가 정확히 유지되는 **상대 좌표계(%)** 기반 설계.

3. **대형 단어 카드 포커스 모드 (Flashcard Mode)**
   - 가림판의 힌트/단어와 가려진 실제 영역을 화면 중앙에 **기존 2배 크기의 대형 플래시 카드** 형식으로 띄워 집중 퀴즈를 진행합니다 (교실 맨 뒤에서도 선명한 가독성).
   - **단어 카드 상태 단축키 연동**: 단어 카드 포커스 상태에서도 `Space` 또는 `→` 키를 누르면 다음 가림판의 단어 카드로 자연스럽게 넘어가며 순차 학습이 가능합니다.
   - 클릭이나 `Enter` 키로 가림 상태와 정답 공개 상태를 즉시 토글할 수 있습니다.
   - 교육적인 플래시 카드 SVG 아이콘 적용.

4. **수업용 가림판 스타일 테마**
   - **칠판 다크 (Slate Black)**: 눈이 편안한 수업용 다크 마스크
   - **포스트잇 (Sticky Yellow)**: 화사하고 주목도 높은 메모형 마스크
   - **클래스 블루 (Modern Blue)**: 깔끔한 강조용 블루 마스크
   - **교사용 힌트 (Blur Mode)**: 교사에게는 흐릿하게 비쳐 보이고 학생에게는 가려지는 반투명 블러 마스크

5. **스마트한 순차 공개 (지우기) 엔진**
   - **단축키 제어**: `Space` 또는 `→` 키를 누르면 1번부터 차례대로 스무스한 페이드 아웃/블러 트랜지션과 함께 가림판이 지워집니다.
   - **이전 복구**: 실수로 지웠을 때 `←` 키로 방금 지운 가림판을 즉시 복원합니다.
   - **직접 클릭 공개**: 특정 번호의 가림판을 마우스로 클릭하면 순서와 관계없이 해당 가림판만 먼저 열 수 있습니다.
   - **일괄 제어**: 모든 가림판 다시 가리기(`R`), 모든 가림판 한 번에 공개(`A`).
   - **오디오 피드백**: 가림판이 지워지고 복구될 때 부드러운 사운드 피드백 제공 (Web Audio API).

6. **수업 준비 데이터 및 템플릿(프리셋) 보관함**
   - **교재 무관 프리셋 저장**: 특정 교재 파일과 독립적으로 마스킹 형태와 텍스트를 이름별로 브라우저 로컬 저장소에 저장하고 필요할 때 원클릭으로 다시 불러올 수 있습니다.
   - **JSON 파일 보관**: 교무실이나 집에서 구성한 가림판 설정을 `.json` 파일로 내보내거나 불러올 수 있습니다.

7. **수업 프레젠테이션 최적화 편의 기능**
   - **초슬림 플로팅 진행상황 패널 & 위치 드래그**: 패널 좌측 그립 핸들을 끌어다 화면 원하는 곳으로 배치할 수 있으며, 높이 최소화 및 텍스트 줄바꿈 방지로 수업 자료를 가리지 않습니다.
   - **수업 진행(전체) 모드 사이드바 자동 숨김**: 수업에 집중할 수 있도록 전체 모드 진입 시 사이드바가 자동으로 닫힙니다.
   - **전체화면 모드 시 자동 가로 맞춤**: 전체화면(`F` / `F11`) 진입 시 항상 화면 너비 맞춤(Fit Width)이 기본으로 자동 적용되어 빔프로젝터/전자칠판에 꽉 찬 뷰를 제공합니다.
   - **Ctrl + 마우스 휠 줌**: `Ctrl` 키를 누른 채 마우스 휠을 굴려 원하는 배율로 부드럽게 확대/축소할 수 있습니다.
   - **사이드바 하단 단축키 가이드**: 왼쪽 패널 하단에 주요 단축키 안내 카드가 상시 표시됩니다.

## ⌨️ 단축키 안내

| 키 (Key) | 기능 설명 |
| :--- | :--- |
| **`Space`** 또는 **`→`** | 다음 순번 가림판 지우기 / 단어 카드 포커스 시 다음 카드로 이동 |
| **`←`** | 방금 지운 가림판 복구 / 단어 카드 포커스 시 이전 카드로 이동 |
| **`C`** | 단어 카드 포커스 모드 열기 / 닫기 |
| **`Enter`** | 단어 카드 포커스 모드에서 카드 내용(정답) 공개 / 가림 토글 |
| **`Ctrl + 휠`** | 뷰포트 확대 / 축소 (Zoom In / Out) |
| **`R`** | 모든 가림판 다시 가리기 (처음 상태로 리셋) |
| **`A`** | 모든 가림판 한 번에 전체 공개 |
| **마커 마우스 드래그** | 이미 생성된 가림판 박스를 원하는 위치로 이동 |
| **가림판 더블클릭** | 가림판에 힌트/단어 텍스트 직접 입력 및 편집 |
| **가림판 직접 클릭** | 순서와 상관없이 해당 번호의 가림판 즉시 공개/가리기 |
| **진행 패널 핸들 드래그** | 하단 플로팅 진행 바를 화면 원하는 위치로 이동 |
| **`F`** / **`F11`** | 전체화면 모드 토글 (자동으로 화면 가로 너비 맞춤 적용) |
| **`PageUp` / `PageDown`** | PDF 다중 페이지 문서 이전 / 다음 페이지 이동 |
